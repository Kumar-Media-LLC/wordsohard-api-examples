# JavaScript

`define.mjs` looks up a word with plain `fetch`. No dependencies.

```bash
node define.mjs serendipity
```

```
SERENDIPITY: valid, 17 points (bingo)
  (noun) The faculty of making fortunate discoveries by accident or luck.
Definitions by WordSoHard (https://wordsohard.com)
```

In the browser, copy the `define()` function. CORS is open, so it works from any domain.
