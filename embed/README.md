# Drop-in embed

Show a styled definition card on any page with no code beyond two tags:

```html
<div data-wsh-define="serendipity"></div>
<script src="https://wordsohard.com/embed.js" async></script>
```

Add as many `data-wsh-define` divs as you like. Include the script once per page.

Works in WordPress (Custom HTML block), Ghost (HTML card), Squarespace (Code block), Webflow (Embed), and plain HTML. The card carries the WordSoHard credit, so it meets the attribution terms automatically.

Open [`index.html`](index.html) in a browser for a word-of-the-day page built this way.
